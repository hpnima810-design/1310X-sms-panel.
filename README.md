# ßnđərX — نمونه اولیه Serverless
این بسته یک پنل آزمایشی فارسی برای Cloudflare Pages است.

## راه‌اندازی
1. محتویات ZIP را در مخزن GitHub قرار دهید.
2. در Cloudflare Pages مخزن را متصل کنید.
3. Build command را خالی و output directory را `public` بگذارید.
4. متغیر محیطی `ADMIN_PASSWORD` را در تنظیمات پروژه تعریف کنید.
5. Deploy کنید.

## فایل مخاطبان
CSV باید ستون‌های `phone` و `consent` داشته باشد. فقط ردیف‌های با consent برابر yes، true، 1 یا بله پذیرفته می‌شوند. شماره‌های تکراری حذف می‌شوند.

## نکات مهم
این نسخه نمایشی است. ارسال واقعی خاموش است و تا دریافت API رسمی ارائه‌دهنده خط خدماتی ۵۰۰۰۰ فعال نمی‌شود. کلید API را هرگز در GitHub یا کد مرورگر قرار ندهید.
